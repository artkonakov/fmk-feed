# FMK feed

Прототип ленты ребёнка: скролл из карточек мест и маршрутов.
Макет — Figma «2026 H2 OKR — Growth», нода `11668:397454`.

## Запуск

```bash
python3 serve.py --port 8120
```

`serve.py` взят из Places-on-map: отдаёт без кеша и печатает адреса для телефона (`--adb`, `--https`).

## Маршруты

- `index.html` — меню: «Вариант А / Б / В / Г», без подписей, буквы перемешаны.
- `?p=a` — карточка маршрута «карта сверху, текст и чипы под ней» (Figma `11668:398053`).
- `?p=b` — контрольный, в меню выключен, сделаем в конце.
- `?p=c` — таймлайн слева от карточек (Figma `11668:401539`).
- `?p=d` — базовая лента, чипы на карте (Figma `11668:397454`).
- Старые ссылки `?p=v1 / v2 / v3` открывают то же самое под новой буквой.

Лента (места, маршруты, время) у всех вариантов одна — `DAYS` в `src/data.js`.

## Структура

```
src/data.js      ребёнок, места, лента (DAYS), меню вариантов (VARIANTS)
src/routes.js    геометрия маршрутов, снята с OSRM и зашита — карта статичная
src/feedmap.js   MapLibre без интерактива: линия, пины, кадр под чипы
src/app.js       меню, шапка, карточки
assets/figma/    иконки из макета
assets/          стиль карты, фото и иконки шапки из Places-on-map
```

Карта — стиль «Findmykids V2 beta light» из Places-on-map (`assets/map-light.json`),
тайлы с CDN Findmykids, токен не нужен. Район — Ховрино, как на макете.
