# FMK feed

Прототип ленты ребёнка: скролл из карточек мест и маршрутов.
Макет — Figma «2026 H2 OKR — Growth», нода `11668:397454`.

## Запуск

```bash
python3 serve.py --port 8120
```

`serve.py` взят из Places-on-map: отдаёт без кеша и печатает адреса для телефона (`--adb`, `--https`).

## Маршруты

- `index.html` — меню: «Вариант А / Б / В / Г / Д», без подписей, буквы перемешаны.
- `?p=a` — карточка маршрута «карта сверху, текст и чипы под ней» (Figma `11668:398053`).
- `?p=b` — контрольный, в меню выключен, сделаем в конце.
- `?p=c` — таймлайн слева от карточек (Figma `11668:401539`).
- `?p=d` — каждый день единым белым блоком, карточки с чипами на карте (Figma `11668:397454`), заголовок дня прилипает.
- `?p=f` — карточки как в контрольном (Б), но в одну строку: длительность слева, время со стрелкой справа; у места под длительностью название; день — капсулой, как в А/В/Г.
- Старые ссылки `?p=v1 / v2 / v3` открывают то же самое под новой буквой, `?p=g` (бывший «Е») — вариант Г.

Лента (места, маршруты, время) у всех вариантов одна — `DAYS` в `src/data.js`.

## Языки

- По умолчанию русский: карта — Ховрино, Москва (`src/routes.js`).
- `&lang=en` (например `?p=a&lang=en`) — английский: карта — Сквиррел-Хилл, Питтсбург
  (`src/routes-us.js`), подписи карты латиницей, время 12-часовое, мили и mph.
- Тайминги, длительности и число событий у обоих языков одни и те же: в `data.js`
  только числа, тексты и форматы собирает `src/i18n.js`.

## Тема

Светлая или тёмная — по системной настройке (`prefers-color-scheme`), меняется на лету.
Цвета — токены коллекции Color TENET из Figma, режимы «FMK – Light» / «FMK – Dark»
(тёмный макет — `12038:285889`), лежат переменными в `:root` в `styles.css`.
Карта переключается между `assets/map-light.json` и `assets/map-dark.json`
(тёмный стиль Findmykids из Places-on-map), маршрут на тёмной карте белый.

## Если карта не загрузилась

Вместо живой карты встаёт картинка из `assets/map-fallback/` — по одной на маршрут,
язык и тему (20 штук). Камера картинки и живой карты считается одинаково
(`src/mapcamera.js`), поэтому пины, подписи и чипы остаются живыми и стоят там же.
Картинка включается, если MapLibre не загрузился, нет сети или за 8 секунд не пришло
ни одного тайла. `&map=off` — сразу картинки, чтобы проверить или показать этот режим.

Перерисовать картинки (например, после смены маршрутов или стиля карты):

```bash
python3 tools/save_fallback.py   # в одном терминале, порт 8121
python3 serve.py --port 8120     # в другом
```

и открыть `http://localhost:8120/tools/render-fallbacks.html` — страница сама отрисует
все карты и сохранит их в `assets/map-fallback/`.

## Структура

```
src/data.js      ребёнок, места, лента (DAYS), меню вариантов (VARIANTS)
src/i18n.js      язык (?lang=en), словарь ru/en, форматы времени, расстояний, окончаний
src/routes.js    маршруты для русской версии (Москва), сняты с OSRM и зашиты
src/routes-us.js маршруты для английской версии (Питтсбург)
src/feedmap.js   MapLibre без интерактива: линия, пины, кадр под чипы, запасные картинки
src/mapcamera.js проекция и кадр без MapLibre — общий для карты и картинок
src/mapstyle.js  стили карты, цвета маршрута, латинские подписи
tools/           отрисовка запасных картинок карт
src/app.js       меню, шапка, карточки
assets/figma/    иконки из макета
assets/          стиль карты, фото и иконки шапки из Places-on-map
```

Карта — стили «Findmykids V2 beta» light / dark из Places-on-map (`assets/map-*.json`),
тайлы с CDN Findmykids, токен не нужен. Район — Ховрино, как на макете.
